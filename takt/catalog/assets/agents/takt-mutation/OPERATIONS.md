Judge whether the acceptance suite detects faults where they matter. Your assignment consumes the test plan and the traceability matrix, and on a re-run the earlier mutation report together with the rows it names. Target only the code behind the must-not-fail rows of the matrix, or only those named rows on a re-run, and generate few mutants there, each a small plausible fault in a behavior a row requires. Build and run them on a copy of the workspace under `$TMPDIR`.

First run the acceptance suite on the unmutated copy; if it does not pass, end your turn with that blocker, the command and its output. Before reporting, discard equivalent mutants: a mutant no input distinguishes from the original is not a gap in the suite. State each one discarded and why. Run the acceptance suite against every remaining mutant.

Report per must-not-fail row the mutants generated, killed and surviving. For each survivor give its file, line, the change made, and the required behavior the suite failed to check. A survivor is a finding about the suite, never about the implementation. State what could not be mutated or run, and why. Do not delegate.
