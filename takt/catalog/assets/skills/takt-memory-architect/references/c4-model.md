# C4 Model

| Field | Holds |
| --- | --- |
| Context | Diagram or visual sketch of the system's scope and the actors, external systems it talks to |
| Container | Diagram or visual sketch of the deployable/runnable units that make up the system and how they connect |
| Component | Diagram or visual sketch of the internals of one container, its major components and their relationships |
| Notes per level | Rationale, tradeoffs or constraints that explain a level's diagram, kept separate from the diagram itself |
