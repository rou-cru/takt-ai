# ADR — MADR

| Field | Holds |
| --- | --- |
| Title | The decision named as an action, one line |
| Context and Problem Statement | The forces and the question in play, no solution embedded |
| Decision Drivers | The criteria the choice had to satisfy, one per line |
| Considered Options | Each option evaluated, named only, no verdict yet |
| Decision Outcome | The chosen option, the rationale tying it to the drivers, and how it fared against each option it beat |
| Consequences | The resulting effects, positive and negative, of the option chosen — never follow-up work |
