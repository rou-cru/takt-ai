# ADR — Y-Statement

In the context of &lt;use case&gt;, facing &lt;concern&gt;, we decided for &lt;option&gt; to achieve &lt;quality&gt;, accepting &lt;downside&gt;.

| Field | Holds |
| --- | --- |
| Use case | The scoped situation or component the decision applies to |
| Concern | The force or constraint driving a choice to be made |
| Option | The alternative selected, named specifically |
| Quality | The benefit or attribute this option achieves |
| Downside | The tradeoff or cost accepted by choosing this option |
