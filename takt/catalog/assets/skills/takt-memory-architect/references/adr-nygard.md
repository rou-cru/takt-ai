# ADR — Nygard

| Field | Holds |
| --- | --- |
| Title | Short noun phrase naming the decision, not the problem |
| Context | The forces in tension — technical, business, or organizational — that make a decision necessary |
| Decision | The choice made, stated as a firm sentence, with the rationale for choosing it over the alternatives |
| Consequences | The resulting effects, good and bad, that follow from the decision taking effect |
