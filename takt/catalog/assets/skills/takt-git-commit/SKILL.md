# Takt Git Commit

**Write a Conventional Commit.** `type(scope): subject`, using this repo's existing types
(`feat`, `fix`, `refactor`, `chore`, `docs`, `test`, `ci`, `build`, `style`, `perf`, `revert`).

**Keep it short.** One line. Add a body only when the subject can't carry it.

**No signature or attribution trailer**, unless the user says otherwise for that commit.
