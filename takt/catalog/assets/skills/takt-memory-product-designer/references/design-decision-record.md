# Design Decision Record

| Field | Holds |
| --- | --- |
| Decision | The one interaction/UX call made, stated as a single sentence |
| Alternatives considered | Other options weighed and why each was rejected |
| Criteria | What this was judged against — usability, accessibility, consistency, constraint |
| Evidence | What was already observed or tested that supports the call — never validation planned for later |
| Outcome | What ships as a result — the rule, invariant, or commitment now in force |
