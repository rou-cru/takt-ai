# Design System Spec

| Field | Holds |
| --- | --- |
| Components covered | The named list of UI components this spec governs for the surface, scoped to one product surface. |
| States per component | Every required interaction state per component (idle, focus, selected, disabled, error, loading, empty, and surface-specific states), with N/A states named rather than omitted. |
| Interaction behavior | The input-to-response contract per component: triggering input, resulting transition, and what stays unchanged across it. |
| Tokens consumed | The semantic design tokens each component/state maps to, referencing the Design Tokens document by name, never restating token values. |
| Accessibility notes | The accessibility commitments each component and state must satisfy (keyboard reachability, focus visibility, non-color state distinction, labeling). |
