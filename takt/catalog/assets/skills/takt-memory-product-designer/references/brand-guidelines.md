# Brand Guidelines

| Field | Holds |
| --- | --- |
| Strategy/positioning | Who the brand is for, what it stands for, and how it differs from alternatives |
| Voice | Tone, vocabulary, and verbal personality to keep consistent across writing |
| Visual identity at a glance | Summary references to the brand's core visual assets (logo, mark, identity elements), not their specification |
| Cross-surface application rules | How the identity adapts across surfaces (site, docs, product, software) while staying recognizable |
| Do/Don't | Boundary cases for correct versus incorrect use of the identity |
