# Style Guide

| Field | Holds |
| --- | --- |
| Color palette + rationale | Named colors and their assigned roles, with the reasoning behind each choice (contrast, mood, precedent) |
| Typography + pairing | Typeface(s) chosen, their roles (e.g. heading vs. body), and why they pair well together |
| Spacing/size scale | The stepped set of spacing and sizing values the surface uses, and the increment logic behind it |
| Hierarchy/rhythm rules | How the scale and type establish visual order and reading flow across the surface |
| Surface it applies to | The single, named surface this guide's fundamentals are scoped to |
