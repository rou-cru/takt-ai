# FRD

| Field | Holds |
| --- | --- |
| Feature area | The bounded group of related behaviors this document is the home for |
| Related behaviors | Each behavior in the area with its observable acceptance rule, one line each; may point to a BDD spec for scenario-level detail |
| Constraints | Observable limits and rules the area must hold to, regardless of behavior |
| Out of scope | Behaviors or areas explicitly excluded from this document |
