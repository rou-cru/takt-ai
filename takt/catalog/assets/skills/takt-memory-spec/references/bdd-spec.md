# BDD Spec

| Field | Holds |
| --- | --- |
| Feature | The one bounded capability under test, named from the user's perspective |
| Scenario | One observable case for the Feature, titled by the situation it covers; a Feature holds one or more |
| Given | The starting state or precondition the scenario assumes |
| When | The single triggering action or event the actor performs |
| Then | The observable outcome that confirms the behavior, stated as acceptance criteria |
