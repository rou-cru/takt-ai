# Trade-off Analysis

| Field | Holds |
| --- | --- |
| Question | The decision the comparison settles, framed so an option can win or lose it |
| Options compared | The 2+ named approaches under comparison, each identified before this analysis started |
| Criteria | The dimensions every option is scored against, listed once and applied uniformly |
| Evidence per option | Verified facts and hypotheses, stated as such, mapped to each option against each criterion |
| Recommendation | A proposal naming the favored option and why, never a directive — adoption is another role's decision |
