# PRD

| Field | Holds |
| --- | --- |
| Problem | The user or business pain this addresses, and who feels it |
| Goals | The outcomes that define this effort worth doing, stated as intent, not tasks |
| Scope | What is in and explicitly out, by capability — never by phase or date |
| Priorities | The relative importance ranking among in-scope items, ordered high to low |
| Risks | Identified risk factors and how each is currently mitigated or accepted |
| Success criteria | The observable signal that goals were met, stated so it can be checked |
