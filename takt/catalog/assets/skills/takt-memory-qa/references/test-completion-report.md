# Test Completion Report

| Field | Holds |
| --- | --- |
| Testing performed | The quadrants, levels and sessions that ran, with the test plan entry they ran against and the ID of each mutation, exploration and quality report consumed |
| Deviations from plan | Each way testing departed from the plan, and its reason |
| Completion evaluation | Each exit criterion and each item of the effective Definition of Done as met or unmet, with its evidence |
| Matrix evidence | Each traceability matrix row with its evidence and evaluated scope, or marked as lacking evidence |
| Residual risk | Every finding left open, every row lacking evidence, and every surviving mutant unresolved on a must-not-fail row |
| Reusable test assets | The tests, data, fixtures and charters that remain usable, with their location |
| Lessons learned | What this testing revealed about the strategy, plan or tooling, stated as findings |
