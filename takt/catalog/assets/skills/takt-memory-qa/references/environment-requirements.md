# Environment Requirements

| Field | Holds |
| --- | --- |
| Established environment | The analyst's environment facts this builds on, cited by entry ID and never restated |
| Services | Each service beyond what the repository runs, with the version or behavior the plan needs |
| Data | The test data the plan needs, its shape and origin |
| Configuration | The settings and flags the plan needs; secrets by name only, never their values |
| Platforms | The operating systems, runtimes, browsers or devices the plan covers |
