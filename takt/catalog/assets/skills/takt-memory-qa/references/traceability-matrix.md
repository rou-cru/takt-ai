# Traceability Matrix

| Field | Holds |
| --- | --- |
| Requirement | The requirement's ID and the specification entry it comes from |
| Test condition | What a test must show for the requirement to hold, or the explicit absence of one |
| Must-not-fail | Whether the row carries a must-not-fail risk of the test plan, marked by `qa` |
| Owning node | The DAG node that delivers the row, added by `tpm` in a supplementing entry |
| Evidence | The test or check that shows the row and the scope it evaluated, added by `verify` in a supplementing entry |
