# Test Plan

| Field | Holds |
| --- | --- |
| Objective | The objective, with the specification, contracts and test policy it is planned from, by entry ID |
| Quadrants | Each quadrant selected and the acceptance need that selects it |
| Test levels | Each level chosen and what it covers |
| Must-not-fail risks | Each risk the objective cannot tolerate, with the requirements it rests on |
| Entry criteria | The condition under which each planned quadrant's testing starts |
| Exit criteria | The conditions under which testing of the objective is complete |
| Effective Definition of Done | The policy's default together with any tightening this objective adds |
| Charters | For Q3 only, each session's area, risk and heuristics |
