# Security Policy

## Supported Versions

Only the latest release receives security fixes.

## Reporting a Vulnerability

Please do not open a public issue for security problems.

Report privately through
[GitHub private vulnerability reporting](https://github.com/rou-cru/takt-ai/security/advisories/new).
Include the affected version, steps to reproduce, and the impact you observed.

Reports are triaged by the maintainers. Confirmed vulnerabilities are fixed in a
new release and disclosed through a published security advisory.
